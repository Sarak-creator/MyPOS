# អាណាចក្រPOS (Anachak POS) - Enterprise ERP & POS System

ប្រព័ន្ធគ្រប់គ្រងការលក់ POS, ឃ្លាំងស្តុក (Inventory), សេវាកម្មជួសជុល (Repairs), គណនេយ្យ (Accounting), ធនធានមនុស្ស (HRM), និងការទូទាត់ Bakong KHQR កម្រិតសហគ្រាស។

## 🚀 ការដំណើរការប្រព័ន្ធ (Getting Started)

1. **ដំឡើង Dependencies:**
   ```bash
   npm install
   ```

2. **បង្កើត Database Schema (Prisma):**
   ```bash
   npx prisma generate
   npx prisma db push
   ```

3. **ដំណើរការ Local Development Server:**
   ```bash
   npm run dev
   ```

4. **បើក Browser:**
   ចូលទៅកាន់ `http://localhost:3000`
